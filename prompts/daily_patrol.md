# 每日巡检提示词（交易日 20:00）

> 用途：本文件是这条定时任务的唯一事实源——调度器 prompt 只放指针（读本文件全文执行），不内嵌正文；改本文件即生效，不动调度器。
> 适用：invest 技能、单账本 50k；对应 `SKILL.md` §8.1。
> 定位：**巡检 = 记账 + 报账**。报买/卖什么、今天赚亏多少、持仓什么样；发现异常只记录，不修。

## 固定部分（不改）

本会话已加载 invest 技能就不调用 skill 工具。

> 解释器约定：下文 `& $py X.py` 均指用技能 venv 跑：`$py = 'D:\skills\invest\stock\.venv\Scripts\python.exe'`（PowerShell 里先赋值再用）。

一、开窗
跑 `billing.py --task-begin --ledger 50k --note 每日巡检`（只开一次；失败记一句原因照跑，收口不许手填数字）。

二、执行（只撮合已生效的条件单，不新建订单）
1. `paper_exec.py --ledger 50k`（不带 `--date` = 结算到最近交易日）
2. `patrol.py --date auto --brief`（唯一巡检命令；负责结算账本、写当日 `nav` 与 `daily_log`）

任一步失败：报 rc 与末行报错，不重跑、不补跑。

三、收口
跑 `billing.py --task-end --ledger 50k --note 每日巡检`，把末行「50k 记 X.XXXX 元」照抄进汇报。

四、汇报（默认四行；确有急事可加说明）

```
巡检 <日期>：<patrol 第一行原样照抄>
今日成交：<paper_exec 成交明细，一只一行；没有成交就写「无」>
需动作：<patrol 第二行原样照抄；没有就写「无」>
本次实扣：X.XXXX 元
```

- 默认就是上面四行；不解释口径、不列维护项、不写「我做了什么」、不复述技能规则。
- **真有急事可以多说**：需动作含高风险、止损/熔断触发、数据或脚本异常、账本数字对不上、需要用户当天决定的情况，允许在四行之后补 ≤3 行——只讲「为什么该动 / 风险是什么 / 什么时候处理」，不写排查过程、不复述脚本原文、不给多套方案。
- patrol 第三行（知道即可）只在确有内容时追加一行；取数异常压成半句跟在末行后。

五、只记录，不修（硬规则）

发现任何缺陷、口径不一致、数据滞后、脚本报错 → **只** 往 `stock/data/invest/out/patrol_findings.md` 追加一行：

```
- <日期> · <一句话事实> · 影响：<一句>
```

**不修代码、不改配置、不跑自检、不提交、不 push、不起子代理、不写报告、不做归因分析。** A/B 分类与修复一律留给决策日（第 10 步 / 月报 L7）。同一问题已记过就跳过，不重复记。

六、硬约束

- 只跑 `paper_exec` / `patrol` / `billing` 三条技能内脚本（billing 只在开头开窗、结尾收口各一次）；不跑取数/计划/决策脚本，不 `Start-ScheduledTask`，不改共享缓存。
- 不改账本、不改 `config`、不编数字、不采集事件面。
- **动作边界**：除「条件单已触发」外不做任何调仓。行业超限、赎回费窗口、净值陈旧、利率未实测等告警只记录与提示，留到决策日处理，不许借告警临时买卖。
- 完成即交还，不写「下一步建议」，不问用户问题。
