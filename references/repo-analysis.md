# §8.11 逆回购盈亏分析框架（`SKILL.md` §8.11）

**定位**：逆回购是**等报价的投资层工具**，不是现金层的常驻仓位。平时观望资金在全市场货基池（§5.7b）；只有 `repo_pulse.py` 判 GO 时才临时打一笔。备选口径：`cash_policy="orders_mf_idle_repo7"` 时按「观望资金按金额分档买 7/14/28 天期、每周一操作一次」执行。
参数：`CAPITAL.cash_layer.repo_pulse`（`min_edge_bp=30`、`max_hold_days=10`、`bench_from="sleeve"`）；**期限选择**走 `repo_pulse.choose_term()`（按同窗口净 %-天取最大，1/7 天期自动比、14 天期需 `--rate14`、28 天期不自动推荐；锁定期要建仓传 `--need-build` 强制 1 天期）；期限费率在 `config.PAPER["cash_yield"]["term_fee_rates"]`（1 天 0.001%、7 天 0.005%、14 天 0.010%、28 天 0.020%）——**利率不在这里**，逆回购/朝朝宝利率统一走 `config.cash_rates()`；备选口径的期限分档在 `CAPITAL.cash_layer.repo_term_ladder=[[20000,28],[8000,14],[0,7]]`。
**判断公式**：`edge_annual = 报价 − bench（半流动性货基加权 90 天年化）− 费年化`，`费年化 = 单笔费率 × 365 / 占款天数`。单笔按占款 1 天折算 ≈ 0.365%/年（每交易日滚一遍全年合计 ≈ 0.25%/本金），**跨长假买 1 天期占款 9 天才 0.0406%/年**——所以甜点是长假的最后交易日，不是日常。

两层口径不能用同一把尺子：
- **权益层**按「决策→成交→评估」窗口：**决策 → 次一交易日卖出按开盘价/买入按限价条件单 → 之后按每日巡检的 `nav` 逐日记录，下一个决策日评估**；决策日无变更则本期不调仓，`nav` 曲线照常记录。
- **现金层**按**持有天数**：观望资金在全市场货基池（按支数/快赎额度管理、T+0/T+1），朝朝宝顶流动性；逆回购按 §5.7c 脉冲择时——期限按净 %-天取最大（1/7 天期自动比、14 天期需给报价；跨周末/长假按实际占款天数计息）。**默认不按「周一固定买 7/14/28 天期」操作**（备选口径见下）。

账本口径（`paper.py`，状态字段 `repo_history` / `repo_open`）：
1. **备选口径（`cash_policy="orders_mf_idle_repo7"`）**：每个操作日（周一）按观望资金金额选 7/14/28 天期，1,000 元整手进逆回购、零头留朝朝宝。默认口径不建常驻仓：只在 `repo_pulse.py` 判 GO 的脉冲日打一笔，期限由 `choose_term()` 决定（按净 %-天取最大，1/7 天期自动、14 天期需给报价），见 §5.7c。挂单资金一律不进逆回购。
2. **只有已到期的 lot 才把利息落进现金**；窗口最后一天那笔记「在途 lot」（`repo_open`），下次结算兑现——同一天重复调用返回 0，不会重复计息。
3. 手续费按期限收（见上表参数），货基 0。
4. 指标：`ops`（笔数）、`covered_days`、`span_days`、`idle_days = span − covered`、`interest`、`fees`、`net`、`effective_annualized = (利息−手续费)/(平均投入×覆盖天数/365)`、`fee_drag = 手续费/利息`。
5. 判读：`idle_days > 0` 说明有现金没进逆回购（或长假覆盖不完，要换更长档）；`fee_drag` 高说明操作太碎；实得年化应 ≈ 逆回购利率 ×(1 − fee_drag)。
6. 报周报/月报**必须把权益层盈亏和现金层利息分开列**，不许用一个总收益掩盖结构（总收益正、权益层负 = 钱是躺着赚的）。

产出：周报 HTML 的「策略与持仓」卡（KPI + 最近 20 笔 lot）、周报 Markdown 一句话结论下、月报「逆回购」行；`paper.repo_pnl()` 随时可调。
