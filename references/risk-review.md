# §9 风险等级与评审 R1–R5（`SKILL.md` §9）

> 等级划分与四条闸门以本文件为准，代码实现见 `scripts/risk.py`、`plan.py`，`SKILL.md` §9 只留指针。

本技能**只做 R2 与 R3**。R1–R5 是金融产品风险等级的**通用划分**，按**产品类型/交易场所/板块**判定，**不按自定义波动率阈值降级**。投资者风险承受能力 C1–C5 须与产品等级匹配：**不能买风险等级高于自身承受能力的产品**；本技能默认 C3（平衡型，可买 R1–R3）。等级不是标签，是四条硬闸门：定级 → 准入 → 预算分配 → 组合评审；评审不过就**不建新仓**（fail-closed）。

| 等级 | 标准定义 | 典型产品 | 本技能怎么处理 |
|---|---|---|---|
| R1 低风险 | 本金损失可能性低、净值波动小、结构简单、流动性高 | 国债、银行存款、货币基金、银行现金管理类理财、保本型理财、逆回购 | **不做投资标的**，只由现金层承担（挂单资金朝朝宝 + 观望资金半流动性货基池；逆回购仅脉冲择时，§5.7c；保守档可用 R1 现金管理类理财，见 §8.11） |
| R2 中低风险 | 本金损失可能性较低、净值波动较小、结构简单、流动性较高 | 主流银行固定收益类理财、地方政府债、政策性金融债、高等级信用债 | **做**（理财产品层：场内债券 ETF 优先，一手 ≈1.1–1.5 万元、单只 12% 上限买不起时由**场外债券基金**兜底，两条腿互斥），单只 ≤ 本金 12%，**腿预算硬上限 2,300 元**（前瞻净票息 0.958% < 货基 1.08%，多放一年是亏的）、**只数 1 只**（`config.RISK.wealth.otc.max_n`）|
| R3 中风险 | 本金损失可能性中等、波动中等、结构较复杂、特殊情况下可能损失全部本金 | **A 股（沪深主板）股票**、可转债、混合型/固收+基金、股票期权备兑开仓 | **做**（权益层主体）：主板股票 + 宽基/策略 ETF（登记例外），单只 ≤ 本金 10% |
| R4 中高风险 | 本金损失可能性较高、波动较大、结构复杂、流动性较低、可能损失全部本金 | 创业板/科创板/北交所股票、港股通、融资融券、个股期权买入开仓、权益类基金、部分私募基金 | **不做**；且创业板、科创板/北交所/港股通/两融/个股期权另有资产门槛（见「准入」）——本部署本金不满足 |
| R5 高风险 | 本金损失可能性高、波动大、复杂难理解、流动性低、损失可能超过本金 | 期货、期权、私募基金、分级基金、复杂结构化产品、场外衍生品 | **不做**（fail-closed：认不出就不买） |

**为什么不做 R4/R5（次序很重要）**：
- R4 里的创业板/科创板/北交所股票**在等级上就是 R4**
- 权益类基金（含行业/主题/跨境 ETF）按标准是 R4。唯一**登记例外**：场内宽基/策略 ETF 按「分散持有、无杠杆、无单一行业押注」的基金评级通行口径取 **R3**（`config.RISK["etf_map"]["equity_etf_level"]`，填 4 即严格执行「权益类基金 = R4」）。

**「理财产品」落地（两条腿）**：①**场内债券 ETF**（`wealth.py`，`config.RISK["wealth"]`）——可取数、可交易、可溯源、费率透明；②**场外债券基金**（`otc.py`）——赎回费按「实际持有天数」查产品阶梯**（`otc.redeem_fee_at_hold()`、`otc_book.redeem_fee_rate()` 与巡检/周报共用；没写 1.5% 就是 0，费表取不到才退回 1.5% 最严档并在报告「口径」列标明）；**产品持有期（如「180 天持有期」）是合同约束，与「不满 90 天不赎回」的纪律是两件事**：选池按 `otc.max_hold_period_days=30` 过滤，下单侧未到期不生成赎回单。**这是小资金唯一能真正持有 R2 的工具**。**首年净收益 = 年化（净值口径）− 申购费 − 赎回费（满 90 天按实测档，多为 0）**；运作费已逐日扣在净值里，不扣第二遍；CSV 的 `cost_1y` 含运作费，只用于池内排序。**只数（`otc.max_n=1`）、近 3 年 CAGR、加权、全池中位数、与现金层差额、组合年度增量全部现取**（`out/stage1_otc.csv` + `out/stage3_plan.json`；增量 = R2 金额 ×（加权 CAGR − 现金层净利率））。⚠️ 是**过去 3 年债牛里的历史净值口径，不是预期收益**，且为「过去 3 年 vs 当前现金利率」跨期比较，未来很可能跌回现金层。三条并记：①不保本，与「本金不亏」的现金层不是同一等级；②R2 只占本金约 4.6%（封顶 2,300 元 / 本金 5 万）；**两条腿互斥**：同一期只用一条，场内配出一只就只用场内，配不出才用场外承接 R2 预算。**打分口径**：**前瞻净票息 30 / 1 年回撤 25 / 全成本 20 / 规模 10 / 1 年收益 15**，`score_range.ret_1y` 上限 5%。前瞻净票息 = `metrics.fwd_bond_yield()`（国债曲线缓存 3Y/5Y 均值）− 该只运作费；plan 的钱账与 otc 选池**共用同一函数**，各写一遍必漂移。**区间按实测分布校准**（618 只池 fwd_net_rate ∈ 0.23%–1.08%、中位 0.83%）：`score_range.fwd_net_rate = [0.004, 0.011]`——低于 0.4% 记 0 分，1.10% 封顶；**不写 1.1%–1.7%**：那会让 99% 的池子恒为 0 分，30 分维度等于失效。改区间要重跑 `otc.py`，并在提交信息写实测分布。场外腿**无 point-in-time 数据、不做 PIT 回放**，账本侧由 `otc_book.py` 记账（T+1 确认净值成交、市值按累计净值比、赎回费按持有天数），结论只用「首年成本 + 3 年 CAGR/最大回撤」横向比较，不宣称 alpha。

**四条闸门的位置**：
1. **定级**（`risk.stock_level()` / `risk.etf_level()`）：
   - 个股按代码板块：`600/601/603/605/000/001/002/003` = 沪深主板 → **R3**；`300/301` = 创业板 → **R4**；`688/689` = 科创板 → **R4**；`43/83/87/88/92` = 北交所 → **R4**；`110/111/113/118/123/127/128` = 可转债 → R3（本技能不买）；ST/*ST/退 → R5；认不出 → R5。**波动率/回撤只写进 `level_reason` 作提示，不改变等级**。
   - 场内基金按品种：货币/现金 → R1；债券（-债/-国债/-政金债…且非股债混合）→ R2；可转债 → R3；跨境（港/美/日/欧等）→ R4；跟踪创业板/科创板/北交所指数的基金 → R4；行业/主题 → R4；宽基/策略 → 登记例外 R3；商品/期货 → R5；杠杆/分级 → R5；认不出 → R5。
2. **准入**（`risk.access_ok()`）：创业板 ≥10 万元 + 24 个月经验；科创板/北交所/港股通/融资融券/个股期权 ≥50 万元（经验另计）——本部署本金全不满足，报告如实写「需 ≥X 万元，本金不满足」。
3. **预算**（`plan.py`）：R2 先占 `equity_budget × 40%` 但**按 `otc.budget_cap_cny = 2,300` 元封顶**，剩下的才是 R3；R2 预算买不起**场内**一手 → **先由场外债券基金兜底**（`out/stage1_otc.csv`，起投 `max(购买起点,100)` 元、不受场内 800 元最低佣金约束，单只仍受 R2 的 12% 上限）；连场外池也空才转现金层，并在计划里写明「需要本金 ≥ X 元」——转现金层不是错误。
   - **R2 准入线**：场外腿前瞻口径**年化超额 ≥ `otc.min_fwd_excess_annual = 0.0025`（25bp）**才算「值得占额度」（≈6.6bp/季）。前瞻净票息 = 国债 3/5 年到期收益率均值 − 运作费（`metrics.fwd_bond_yield()` 现取曲线缓存）。**不达标只记 `admission.pass=False`、保留风险等级所需最小额度、不再加仓**，不是必须清仓——R2 还承担「小资金唯一 R2 敞口」的结构作用。计划书「这笔钱跟现金层（货基）比，到底赚多少」一节逐项列：后视 CAGR 加权 / 全池中位数 / 与货基差额 / 折算成一年多少钱 / 前瞻净票息与准入结论。
4. **评审**（`risk.portfolio_review()`：单只权重按**占本金**、R2 占比按**已投总额**算）：ERROR 级 = 等级不在 R2/R3、单只超该等级上限、加权等级 > R3.0；任一 ERROR → `plan["risk_review"]["ok"] = False` → `weekly.py` 本期不建新仓（只保留止损/熔断），报告逐条列违规。WARN 级（不拦）：加权等级 < R2.2（太保守）、R2 占比不在 10%–60%、空仓。评审同时输出投资者匹配说明（`investor_line()`）。

**验证**：`selftest_all.py --fast` 跑 30 套离线自检（3 套联网需单独跑，不随 `--fast`），断言项数以汇总行为准、不写死；`doctor.py` 每次决策前检查「持仓等级 ⊆ R2/R3、加权等级在区间内、R4/R5 持仓为 0」；周报 HTML 的「策略与持仓」卡、周报 Markdown 第一节、月报都有等级分布、准入说明与评审结论。

**边界**：等级按**产品类型/板块**分类（发行方评级可不同），不预测未来；R2 债券 ETF 在利率上行期同样会亏（选池门槛不是承诺）。
